A one-line patch note for a bug in real life, written by `main.ts` to `/output/entry.txt`:

> v1.7.3: fixed a bug where crossing a doorway flushed the working-memory cache, dropping the reason you entered the room.

The entry is the doorway effect: walk through a doorway and your brain drops the reason you entered the room — a real, instantly recognisable bug of human memory, written in the terse register of a real release note.

Run it with Node 22+:

```sh
node main.ts
```

It writes exactly one line (120 characters, no trailing newline) to `/output/entry.txt`, deterministically.
